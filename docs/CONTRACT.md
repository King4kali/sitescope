# Integration contract

API prefix `/api/v1`, frontend same-origin rewrite to `API_INTERNAL_URL` (default http://127.0.0.1:4000). Session cookie `sitescope_session`, CSRF: server checks Origin against WEB_ORIGIN for mutating authenticated requests; client sends `X-Requested-With: SiteScope`. Auth response `{user:{id,email,name,role,emailVerifiedAt}}`. Lists `{items,total,page,pageSize}`. Errors `{code,message,requestId,details?}`. GET project includes `audits` (latest 20); each audit has `results` and `_count.findings`. GET audit/report includes `project`, `results`, `findings`, `pages`, `artifacts`, `events`. AuditResult uses `metricsJson`, `rawDataJson`; Finding uses `evidenceJson`. Artifact includes an authorized `url` to `/api/v1/artifacts/:id`. Export polling returns `{id,status,url?,errorCode?}`. Creation audit 202 `{id,status,stage,progress}`. SSE JSON audit snapshot in default message events. Dates ISO strings. Never fabricate unavailable scores; use null.

Prisma schema in root is canonical. root package dependencies managed by coordinator; agents may add their own dependencies only to their workspace package before notifying coordinator. `@sitescope/core` provides contracts, `validatePublicUrl(input):Promise<URL>`, `safeFetch(input, options?):Promise<SafeResponse>`, `inspectTls(url):Promise<object>`, storage `putObject(key,buffer,mimeType)`, `getObject(key)`, `signedObjectUrl(key)`, `deleteObject(key)`. SafeResponse: `{url,status,headers:Record<string,string>,body:Buffer,durationMs,redirects:string[]}`. All untrusted network requests use safety functions, including robots/sitemaps/link checking. Internal service calls use fixed trusted env URLs.

Queue names `audits` and `reports`, payloads `{auditId}` / `{exportId}`, jobId matching record id. API owns outbox dispatch and reconciliation. Worker owns actual analysis, results persistence, stage events, hostname Redis lock, report queue consumer. Browser runner owned by worker agent: `apps/browser/src/main.ts`, POST `/audit` -> BrowserOutput contract, POST `/pdf` `{html}` -> binary PDF. Chromium uses HTTP_PROXY env, sandbox enabled; remote browser container has no DB/storage credentials. Report rendering MUST escape inspected text; do not fetch remote assets while generating PDF.

Worker persists artifacts through core storage. API owner checks ownership before returning images/PDF, using stream via getObject, not publicly accessible bucket. Mail uses SMTP_HOST/PORT and optional SMTP_USER/PASS, Mailpit local. Email verify POST `/auth/verify` `{token}`, resend POST `/auth/resend-verification`, forgot POST `/auth/forgot-password` `{email}`, reset POST `/auth/reset-password` `{token,password}`. Profile PATCH `/users/me` `{name}`, DELETE `/users/me` `{password}`. Admin GET `/admin/stats`, GET `/admin/users`, PATCH `/admin/users/:id` `{blocked}`. GET `/health/live`, `/health/ready` public.
